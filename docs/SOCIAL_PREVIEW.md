# Social preview

Image: [`assets/social-preview.png`](assets/social-preview.png) (1280×640).

GitHub has **no public API** to upload the repo social preview. After push:

1. Open https://github.com/vishalgaur1/VOXORYL/settings  
2. **Social preview** → **Edit** → **Upload an image…**  
3. Choose `docs/assets/social-preview.png`

Until uploaded, link unfurls use GitHub’s auto card.
