# VOXORYL

VOXORYL (say *vox-OR-ill*) is a local voice assistant for your PC. You talk; it opens apps, drives Chrome/YouTube, and helps with your computer — mostly offline. Short name: **Voxy**. Wake it with **“Hey Voxy”**.

This wiki is the short human guide. Full install and flags live in the README — we don’t paste that here.
